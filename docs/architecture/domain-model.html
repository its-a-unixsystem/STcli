Derivation chain · not shown in diagram

The Turn Trace is the authoritative record of commands and recorded outcomes. The Session Projection is a rebuildable view derived from the trace — never the source of truth.

A Turn Capsule is derived from a trace slice. A Portable Capsule embeds all non-redacted content required for replay; a Thin Capsule references content already in the local store. Replay reconstructs from recorded outcomes without live effects; Rerun submits a recorded provider request again as a new attempt.
